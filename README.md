# thesis-info

Source code for the [BSc Thesis Information](https://soriclucija.github.io/thesis-info/) website, a central hub for BSc thesis students supervised by me at Tilburg University.

Built with [Quarto](https://quarto.org) and hosted on GitHub Pages.

## Getting started

### Prerequisites

- [Quarto](https://quarto.org/docs/get-started/)
- RStudio (optional)

### Installation

```bash
git clone https://github.com/soriclucija/thesis-info.git
cd thesis-info
```

### Usage

Preview the site locally:

```bash
quarto preview
```

Build the site:

```bash
quarto render
```

The output is written to `docs/`, which GitHub Pages serves from the `main` branch.
